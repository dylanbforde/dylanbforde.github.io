Case study

Building candidates from altered sequences

01 / Problem

Preserve biological context

For each mutation class, generate candidate 9-mers that match the true altered sequence, without silent padding, truncation, or shifts.

02 / System

Connect sequence and structure

The pipeline matches TCGA records to UniProt or reconstructs them through Ensembl CDS. It encodes the resulting peptides as graphs, scores them with a GNN, and aligns them to learned motifs using log-domain Sinkhorn.

03 / Artifact

Code from preprocessing to reporting

The public repository covers preprocessing, candidate generation, graph construction, training, and prediction. It also includes tests, CSV outputs, and a generated report.

Pipeline detail

Four stages of candidate generation

  1. Normalize variants

    Handle missense, frameshift, and in-frame mutations separately.

  2. Reconstruct sequence

    Recover the wild-type protein context. Where a mutation changes the downstream frame, simulate the altered coding sequence.

  3. Learn representations

    Give each residue node biophysical features, then use graph message passing to estimate peptide–MHC binding.

  4. Rank candidates

    Combine binding estimates and learned motif alignment into candidate outputs that can be audited, with more detail than a final score.

Evidence boundary

Computational candidate design.

The repository demonstrates a computational design pipeline: data processing, model construction, training, and candidate reporting. It does not establish clinical validation or clinical efficacy. The rankings are research outputs that require experimental validation.
