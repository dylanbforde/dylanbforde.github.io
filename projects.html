01Graph AI

Personalized cancer vaccine design

Turning a patient’s variants into a defensible neoantigen shortlist.

The pipeline connects mutation processing, protein sequence reconstruction, graph learning, and peptide–MHC scoring. Its most interesting engineering challenge is preserving biological meaning as messy variant records become fixed-length model inputs.

Problem

Generate candidate 9-mers around missense, frameshift, and in-frame mutations without silently corrupting sequence context.

System

TCGA records are filtered and matched to UniProt or Ensembl sequences, encoded as peptide graphs, scored by a GNN, then aligned to learned motifs with log-domain Sinkhorn.

Public artifact

An end-to-end Python repository with preprocessing, candidate generation, training, prediction, tests, and report outputs.

02Adaptive networks

FORDE vision–language model

A neural network that reorganizes its own functional routes.

FORDE—Functional Organisation via Route-Density Estimation—adds a slower structural loop around ordinary gradient updates. The model collects activation and gradient history, clusters its internal units, smooths the resulting map, and uses that map to alter future routing.

Problem

Most networks adapt weights but leave their computational organization fixed, even when stable functional specialization emerges.

System

A fast loop trains a CLIP-style dual encoder. Periodically, a Sense → Cluster → Smooth → Actuate loop updates stateful route assignments.

Public artifact

A JAX/Flax implementation with a baseline ablation, streaming Conceptual Captions input, brain-map diagnostics, and tests.

03Deep RL

Domain-shift quantification

Estimating whether a policy will survive the next environment.

This dissertation project treats domain shift as something to measure before deployment, not merely observe after performance collapses. A meta model learns signals about policy suitability under upcoming changes.

Problem

A policy that works in one simulated domain can fail when dynamics or observations move, while conventional validation hides the size of that move.

System

Generate controlled shifts, collect policy behaviour across domains, and train a second-order model to estimate compatibility.

Public artifact

Experiment code, tests, dissertation material, and a paper describing intrinsic quantification of domain-shift magnitude.

Reinforcement LearningGeneralizationMeta-model

04Volumetric vision

Cardiac MRI segmentation

Adapting a hierarchical transformer to three-dimensional anatomy.

A notebook-led implementation explores how SegFormer’s efficient multi-scale representation can be carried into volumetric cardiac data, where local boundary detail and long-range spatial context both matter.

Problem

Segment anatomical structures across an MRI volume without discarding the relationships between adjacent slices.

System

Overlapping 3D patch embeddings feed a MixTransformer-style hierarchy; multi-resolution features are decoded into voxel-level masks.

Public artifact

Exploratory notebooks for data loading, segmentation, model construction, training, and saved model checkpoints.

05Medical imaging

MRNet MRI classification

Moving from independent slices to a volume-aware diagnosis.

This experimental notebook project asks how attention can combine evidence distributed through a scan. Rather than collapsing a volume immediately, it develops representations per slice and then aggregates across the study.

Problem

Diagnostic cues may be small, appear on only a few slices, and depend on context elsewhere in the MRI sequence.

System

Patch tokenization and self-attention form slice features; inter-slice aggregation turns variable evidence into a study-level decision.

Public artifact

A sequence of exploratory notebooks covering the architecture, dataset handling, training experiments, and visual inspection.

MRISlice attentionClassification

06Computational biology

Lung adenocarcinoma modeling

Connecting expression data, survival signals, and treatment rules.

The project combines TCGA-LUAD molecular and clinical data into a research workflow for risk stratification, regulatory-network analysis, and explainable treatment recommendation.

Problem

High-dimensional gene expression, censored survival data, and incomplete clinical records must be reconciled before any downstream model is meaningful.

System

Univariate Cox screening and Lasso-Cox produce a risk model; clinical and biomarker rules feed an R6 recommendation system and report.

Evidence boundary

This is a research and educational codebase, not a clinically validated decision system. Reported cohort figures originate in the repository.

07Developer systems

Nix flake and dotfiles

Treating a personal workstation as a reproducible system.

The configuration turns machine setup into reviewed source: hosts compose reusable modules, dependencies are pinned, secrets stay encrypted, and checks catch drift before activation.

Problem

Developer machines accumulate invisible state, fragile installation steps, and credentials that are difficult to audit or reproduce.

System

A flake composes host and user modules, sops-nix decrypts secrets at activation time, and automated checks validate configuration and scan for leaks.

Public artifact

The live configuration structure, pinned flake lock, reusable modules, security policy, and setup documentation.

Generative parking-trace pipeline
